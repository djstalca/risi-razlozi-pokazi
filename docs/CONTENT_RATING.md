# Content rating – IARC osnutek

To je priprava odgovorov za Play Console. Končne odgovore preveri ob oddaji glede na takratno vsebino aplikacije.

## Trenutna v1.0 vsebina

- brez oglasov,
- brez spletnega klepeta ali uporabniško objavljene vsebine,
- brez nakupov,
- brez simuliranega igranja na srečo,
- brez spolne vsebine ali golote,
- brez drog, alkohola ali tobaka kot igralne mehanike,
- brez grafičnega nasilja,
- brez strašenja ali grozljivih grafičnih prizorov,
- brez lokacije in deljenja osebnih podatkov.

Baza pojmov vsebuje vsakdanje besede in poklice/živali/predmete; posamezni pojmi, kot so boksar, lovec ali vojak, so besedni pojmi za ugibanje in niso grafično prikazani kot nasilni prizori.

## Predlagani odgovori

Za standardni IARC vprašalnik je pričakovan profil **brez reguliranih oziroma zrelih vsebin**. Če vprašalnik razlikuje med omembo in prikazom nasilja, odgovori glede na dejansko prikazano vsebino: aplikacija sama ne prikazuje nasilnih prizorov.

Posebej preveri:
- Violence: praviloma **No** za prikazano nasilje,
- Fear/Horror: **No**,
- Sexuality/Nudity: **No**,
- Language: **No** za profanity/vulgar language,
- Controlled substances: **No**,
- Gambling: **No**,
- User interaction / UGC: **No**,
- Location sharing: **No**,
- In-app purchases: **No**.

## Release gate

Če se baza pojmov ali funkcije pozneje bistveno spremenijo, je treba pred izdajo ponovno preveriti IARC odgovore in po potrebi posodobiti oceno.
